# Albion Chat Translator

[English](../../README.md) · [Português (BR)](README.pt-BR.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · **日本語**

Albion Online のチャットを自分の言語で読み、相手の言語で返信できます。

無料、アカウント不要、API キー不要、設定不要。**オープンソース**：すべてのコードが公開されており、誰でも動作を確認できます。

---

## できること

- **読む内容を翻訳。** 他のプレイヤーのメッセージ（Say、Whisper、Party、Guild、Alliance、必要なら全体チャンネル）が届いた瞬間に自分の言語で表示されます。すでに自分の言語のメッセージはそのままです。
- **書く内容を翻訳。** ショートカットを押して自分の言語で入力し Enter を押すと、Albion に貼り付けられる翻訳ができあがります。
- **ゲームの上にチャットを表示。** 任意の半透明オーバーレイで、マウスのクリックはそのままゲームに届きます。

## インストール

1. [**Releases**](https://github.com/MrYellowHeart/AlbionChatTranslator/releases) を開き、`AlbionChatTranslator-win-Setup.exe` をダウンロードします。
2. 実行します。ほかに必要なものはありません（.NET 同梱）。現在の Windows ユーザーにだけインストールされます。
3. 自分が読む言語を選びます。
4. **▶ Start** をクリックし、Windows の確認画面で **はい** を選びます（[理由](#なぜ管理者権限が必要なのですか)）。
5. Albion にログインすると、チャットタブが自動的にアプリに表示されます。

更新は自動的にダウンロード・インストールされます。

## 使い方

### チャットを読む

普通にプレイするだけです。翻訳されたメッセージがアプリ（オンならオーバーレイにも）に表示されます：

```
14:02 Ana: Lymhurst で安い t6.1 バッグを売っている人はいますか？ (Portuguese)
```

- メッセージに**マウスを重ねる**と原文が見られます。
- `(Portuguese)` タグを**クリック**すると、その人の言語で返信できます。
- 自分の言語のメッセージ、ごく短いメッセージ（"gg"、"ok"）、アイテムリンクはそのまま表示されます。

### 相手の言語で返信する

1. ゲーム中に **Ctrl+Shift+R** を押します（またはメッセージの言語タグをクリック）。
2. **自分の**言語で入力し、**Enter** を押します。
3. 翻訳がクリップボードに入ります。Albion でチャットを開き **Ctrl+V**、そして Enter。

返信ウィンドウは最後にメッセージをくれた人の言語にあらかじめ設定されており、変更もできます。
アプリがゲームに何かを入力・送信することはありません。貼り付けて送信するのは常に**あなた**です。

### オーバーレイ

**Ctrl+Shift+O** でゲーム上の半透明チャットを表示・非表示にします。ロック中はクリックがそのまま Albion に届きます。**Ctrl+Shift+L** でロックを解除するとドラッグで移動・サイズ変更でき、もう一度押すとロックされます。

### ショートカット

| キー | 動作 |
|---|---|
| **Ctrl+Shift+R** | 最後にメッセージをくれた人に返信 |
| **Ctrl+Shift+O** | オーバーレイの表示 / 非表示 |
| **Ctrl+Shift+L** | オーバーレイを移動するためのロック解除 / ロック |

Albion がアクティブでも使えます。ほかのプログラムがすでに使っている場合はアプリが知らせます。アプリのボタンでも同じことができます。

### 便利な設定

| 設定 | 用途 |
|---|---|
| **翻訳先の言語** | あなたの言語。 |
| **ほかに読める言語** | 理解できるほかの言語。翻訳も送信もされません。 |
| **翻訳のタイミング** | *自動* または *[translate] をクリックしたときだけ*。 |
| **これらのチャンネルは送信しない** | ささやきやギルドなど、非公開にしておきたいもの。 |
| **これらの単語は翻訳しない** | ギルド名、フレンドの名前、自分のスラング。 |
| **翻訳サービス** | 次の順に使用：**1.** 自分の Microsoft Translator または DeepL のキー（任意、最も安定）、**2.** Google 翻訳（設定不要）、**3.** オフライン予備。それぞれオン・オフできます。 |
| **翻訳を 7 日間記憶** | 再起動後の送信が減ります。既定ではオフ。 |

## 仕組み

1. **チャットの読み取り。** Albion にはアドオンの仕組みがないため、アプリはよく知られたコミュニティツールと同じようにゲームのネットワーク通信を読み取ります。小さな隠れたヘルパーがこれを行い、チャットメッセージだけをアプリに渡します。読むだけで、何かを変更・送信・注入することはありません。
2. **何を翻訳するか。** アプリはあなたの PC 上で、すでに自分の言語のメッセージ、短すぎるもの、アイテムリンクだけのもの、以前に翻訳したものを見分けます。**これらは決して PC の外に出ません。** また Albion の用語（都市、`t8.3` のようなティア、アイテムリンク、"gank"、"zerg"…）を保護し、`lf healer pls` のようなゲーム略語を先に普通の英語に直すことで、翻訳の質を大きく高めます。
3. **翻訳。** 残ったもの、つまりメッセージの本文だけを Google 翻訳（または DeepL）に送り、結果を表示します。
4. **返信。** 入力した文章も同じように翻訳され、クリップボードに入ります。

### なぜ管理者権限が必要なのですか？

Windows ではネットワーク通信を読むのに管理者権限が必要です。アプリはそれを最小限にしています：

- あなたが使うウィンドウは**一般ユーザー**として動きます。
- 権限を受け取るのは、別の小さなヘルパーだけです。このヘルパーにできるのは、Albion のチャットパケットを読み、あなたの Windows ユーザーだけが開ける非公開の一方向の接続でウィンドウに渡すことだけです。
- ヘルパーはインターネットにアクセスせず、ファイルを読み書きせず、命令も受け付けません。

## プライバシー

| Google 翻訳（または DeepL）に送るもの | 決して送らないもの |
|---|---|
| 自分の言語ではないメッセージの**本文** | 自分の言語のメッセージ、短いメッセージ、繰り返し |
| 返信ウィンドウに入力した文章 | プレイヤー名、チャンネル、ギルド名、アイテムリンク |
| | あなたのアカウント、キャラクター、その他のゲームデータ |
| | 除外したチャンネルの内容すべて |

- すべて HTTPS のリクエスト本文で送信し（URL には決して含めません）、Cookie・アカウント・アプリ識別子は使いません。ほかのウェブサイトと同様に、Google にはあなたのインターネット（IP）アドレスが見えます。
- ステータスバーに、PC の外へ出たメッセージ数が表示されます（*Sent for translation*）。
- テレメトリ、解析、広告、チャットログはありません。*翻訳を記憶* をオンにしない限り、ディスクには何も書き込みません。
- DeepL キーを追加した場合は、Windows アカウントで暗号化して保存します。

Google 翻訳は、Google 自身のウェブウィジェットが使う無料の窓口を通して利用します。キーは不要ですが公式 API ではなく、Google は接続ごとに厳しく制限します。チャットが活発だと数分で制限に達することがあります。そのときはアプリが一時的に退き、**オフライン予備**（PC 上で動き何も送信しないモデル。言語ごとに初回だけ約 110 MB をダウンロード）か自分のキーが引き継ぐので、翻訳は止まりません。最も安定させるには、無料の Microsoft Translator または DeepL のキーを追加してください。

## よくある問題

- **何も表示されない。** ステータスが *Capturing* になっているか確認し、Say で何か発言してください。VPN やラグ軽減ツール（ExitLag など）がゲーム通信を隠すことがあるので、オフにして試してください。
- **"Administrator permission was declined"。** もう一度 Start を押して *はい* を選んでください。Windows アカウントが管理者でない場合は、管理者の承認が必要です。
- **Windows SmartScreen がインストーラーを警告する。** リリースはまだコード署名されていません。ファイルのハッシュを確認し（上記）、*詳細情報 → 実行* を選ぶか、自分でビルドしてください。
- **ショートカットが効かない。** ほかのプログラムが使っています。アプリがどれかを表示するので、ボタンを使ってください。
- **"Google is limiting requests; translating offline"。** Google の無料窓口は制限が低めです。オフライン予備が引き継ぎますが、言語ごとに初回は言語パックをダウンロードするため、最初の数行は未翻訳のままになることがあります。無料の Microsoft または DeepL のキーを追加すると避けられます。
